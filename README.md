# Improving User Engagement on Hunch | Product Strategy

## Project Overview
Developed a product strategy to improve user engagement and retention on Hunch, a poll-based social media platform. The project involved competitive benchmarking, market analysis, user persona development, feature ideation, prioritization, and go-to-market planning.

## Key Components

**1. Problem & Market Analysis**
- Identified declining engagement as a potential challenge affecting user retention and platform growth.
- Benchmarked Hunch against competitors including Slick and Yubo.
- Conducted TAM, SAM and SOM market sizing.

**2. User Research & Personas**
- Developed three user personas representing different engagement patterns and motivations.
- Identified key user needs, including rewards, entertainment, appreciation, and a sense of belonging.

**3. Product Feature Development**

Proposed three engagement-focused features:

| Feature | Concept |
|---|---|
| Hunch Bucks | Coin-based rewards system offering coupons and discounts for user engagement. |
| Hunch Arcade | Mini-games featuring Guess the Word and Guess the Winner, rewarding participation with Hunch Bucks. |
| Hunch Express | Open-ended questions posted every four days, with rankings and rewards based on likes. |

**4. RICE Prioritization**

Evaluated the proposed features using Reach, Impact, Confidence and Effort.

| Feature | RICE Score | Rank |
|---|---:|---:|
| Hunch Bucks | 15.0 | 1 |
| Hunch Arcade | 8.1 | 2 |
| Hunch Express | 6.4 | 3 |

**5. Go-to-Market Strategy & Metrics**
- Proposed a phased feature rollout, beginning with Hunch Bucks.
- Recommended social media promotions, brand collaborations, user surveys and feedback.
- Identified KPIs including reward redemption, daily game activity, answer submissions, likes and click-through rates.
